# Skill

Skill is an evidence-first, cross-agent enterprise security research workflow package.

It provides:

- Grok orchestration and progressive specialist routing;
- passive search MCP collection;
- SnowEyes content and browser-runtime collection;
- asset graph normalization, deduplication, prioritization, and handoff;
- focused validation lanes, evidence gates, reporting, and replay support;
- local runtime hooks, supervisors, scripts, references, and test fixtures.
- explicit authorization, asset-graph, hypothesis-ledger, and evidence-quality contracts;
- distilled local knowledge indexes without bundling source PDFs or Office files.
- adapter contracts for Generic Agent, Codex, Claude Code, and Grok;
- capability negotiation, structured handoffs, and offline benchmark regression.

The distribution contains text, code, configuration, and tests only. Runtime
credentials are supplied through environment variables.

Start with `SKILL.md`. The deep routing entry is
`skills/skill/SKILL.md`. Read `references/v22/operating-contract.md` before
enabling active validation. Read `adapters/README.md` when running under a
different Agent framework.
